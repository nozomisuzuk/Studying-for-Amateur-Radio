# 1アマ過去問ドリル

第一級アマチュア無線技士（1アマ）国家試験の過去問をひたすら解き、**間違えた問題**と**苦手なジャンル**を繰り返し解き直すための学習アプリです。ブラウザで動くWebアプリ（PWA）で、スマホ・PCのどちらでも使え、一度開けばオフラインでも動きます。

各30問、計660問（無線工学270問・法規390問）。「—」の回と表にない回は、問題と正答の PDF がそろって保存されていなかったため収録していません。正答は公式の正答表から読み取り、全問を正答表と照合済みです（令和7年5月期 法規 A-7 は公式に「誤植により全員正解」とされた問題で、アプリ内にその旨を表示します）。

古い回の法規の問題には、出題後の法改正で現在の規定と食い違うものがあります（後述の「法改正への対応」）。

### 問題文の表示（原本の画像／文字）

- **原本（画像）** … PDFから1問ずつ切り出した画像。図や数式も試験問題そのままです。PCやタブレットでは既定でこちら。
- **文字で表示** … スマホの縦画面では原本の画像だと文字が小さすぎるため、PDFの文字情報から段落・選択肢・組合せの表・B問題の語群・空欄の枠を組み直して、画面幅で折り返す文字として表示します。図・分数などの式・罫線つきの表は画像のまま埋め込み（タップで拡大）、本文中の短い式（√2 など）は文字と同じ高さの小さな画像にしています。モールス符号は文字の区切りを保って文字で表示します。スマホでは既定でこちら。

どちらも問題ごとのボタンで切り替えられ、設定で「常に文字／常に原本」にもできます。文字表示は660問中639問に用意しています。残り21問は、自動変換の検査（組合せの表の行番号や語群の番号がそろうか、選択肢番号に欠けがないか、図と本文が入り組んでいないか）に通らなかったため、誤った表示を避けて原本の画像だけにしています。

試験の形式（日本無線協会の資料より）: 無線工学・法規とも 30問・2時間30分・150点満点、合格点105点。A問題は1問5点、B問題はア〜オの小設問が各1点。

### 解説

解答すると、問題文の下に解説が出ます（解答欄の「解説」ボタンで移動。模擬試験の結果画面の問題詳細にも表示）。

- **正答を入れた文**（自動）… 空欄補充の問題で、空欄に正答の字句を入れた文。モールス符号の字句には読み（NIL、VA など）を添えます。
- **モールス符号の読み**（自動）… 選択肢の符号を文字に読み下したもの。
- **手書きの解説** … 正答の根拠と、誤りの選択肢のどこが違うかを短く書いたもの。法規（国内法令）は e-Gov 法令検索の現行の条文と照合し、条番号を添えています。国際法規は ITU が公表している英語の正文（無線通信規則 2024年版、国際電気通信連合憲章は基本文書集 2023年版）と照合し、「無線通信規則第25.2A号」「憲章附属書第1003号」のように条項番号を添えています（和文は試験問題の文言に合わせたもので、公定訳そのものではありません）。無線工学の計算問題は途中の式と、Python で検算した値を示しています。
- 本文と正答がまったく同じ問題（別の回の再出題）には、同じ解説を表示します。

全660問に解説があります（HY612 B-1 は法改正の注記のみ）。国際法規の65問は、空欄補充の25問が「正答を入れた文」と根拠の条項番号、残りの40問が手書きの解説です。

### 法規の法改正への対応

e-Gov 法令API から「試験の月に施行されていた版」と「現行版」の条文を取り寄せ、各問題が引用している条文（「電波法（第24条、第78条及び第113条）」など）を比べて、出題後の改正を調べました（`tools/lawcheck.py`）。

- **現在の規定と食い違う問題**（9問）… 令和8年4月1日の免許状の廃止（令和7年法律第27号）により、免許状の返納・訂正を問う問題。解答前に注意書きを出し、解説で現在の規定を示します。おまかせ演習・復習・条件指定の演習・ランダム模試からは既定で外します（問題一覧と過去問の模擬試験には残ります。設定で演習に含めることもできます）。
- **用語などが改正された問題**（27問）…「免許状に記載された」→「免許記録に記録されている」、「懲役」→「拘禁刑」などで、答えは変わらないもの。解説に注記します。

国際法規は e-Gov に無いため、ITU が公表している英語の正文で、出題時の版と現行版を比べました（無線通信規則は 2016年版・2020年版・2024年版、国際電気通信連合憲章は基本文書集 2019年版・2023年版）。問題に関係する条項（無線通信規則の第1条の定義、第3条、第5条のアマチュア業務の分配、第15条、第17条〜第19条、第22.1号、第25条、憲章第37条・附属書第1003号）に変更はなく、国際法規で古くなった問題はありません。

## 主な機能

- **おまかせ演習** … 「復習期日が来た問題 → 苦手ジャンルの問題 → まだ解いていない問題 → しばらく解いていない問題」の順に自動で選んで出題します。迷ったらこれを押すだけでよい設計です。
- **間違えた問題の復習** … 間違えた問題は「要復習」になり、
  1. 同じセットの少し後（3問ほど後）にもう一度出題
  2. 正解すると翌日以降の「今日の復習」に再登場
  3. 日を空けて連続で正解すると「克服」として外れる（必要回数は設定で2〜4回）

  という流れで、解けるようになるまで繰り返し出ます。期日前に正解しても克服までの回数には数えません（直後に覚えているだけの正解を除くため）。
- **苦手ジャンル** … ジャンルごとに「解いたことのある問題のうち、最後の解答が正解だった割合（直近正答率）」を出し、合格ライン70%を下回るジャンルや要復習が多いジャンルを苦手として表示。ジャンル単位・苦手上位まとめての集中演習ができます。
- **条件指定の演習** … 科目・回・ジャンル・A/B問題・未解答のみ/前回不正解のみ/ブックマークのみ・出題順/ランダム/苦手順 などを組み合わせて出題。
- **模擬試験** … 過去の回をそのまま本番形式（30問・2時間30分・タイマー付き・採点は提出後）で。問題番号ごとに過去の各回から1問ずつ選ぶ「ランダム模試」もあります（本試験は分野順に並ぶので、番号をそろえると分野配分が本番と同じになる）。
- **問題一覧・検索** … 回・ジャンル・状態（未解答/要復習/前回不正解/★/メモあり）で絞り込み、問題文やメモをキーワード検索。
- **記録** … 日別の解答数、ジャンル別・回別の正答率、模擬試験の得点推移。
- その他: 1問ごとのメモとブックマーク、押し間違いの取り消し、キーボード操作（数字キーで解答、Enterで次へ）、ダークモード、記録の書き出し/読み込み（機種変更用）。

学習記録はその端末のブラウザ（localStorage）にだけ保存され、外部には送信しません。

## 使い方

### GitHub Pages で公開して使う（スマホで使うならこれ）

1. このリポジトリの **Settings → Pages** を開く
2. Source を「Deploy from a branch」、Branch をこのアプリのあるブランチ・`/ (root)` にして Save
3. 数分後に表示されるURL（`https://<ユーザー名>.github.io/Studying-for-Amateur-Radio/`）を開く
4. スマホではブラウザの「ホーム画面に追加」でアプリのように起動できます。設定画面の「全問題の画像を端末に保存」を押しておくと、電波のない場所でも全問題を解けます。

### 手元のPCで動かす

ES Modules と Service Worker を使うため、`index.html` を直接開くのではなくHTTPサーバー経由で開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## 新しい回の過去問を追加する

日本無線協会は直近の数回分だけを公開し、古い回は順次サイトから消えます。新しい回が公表されたら次を実行すると、公式サイトにある回のうち未取得のものを `source-pdf/` に保存し、問題画像と `data/questions.json` を作り直します。

```sh
pip install -r tools/requirements.txt
python3 tools/build_data.py --download
```

変換スクリプトは次のことを自動で行い、合わない場合はエラーで止まります。

- 問題PDFから「A－1」「B－1」などの見出し位置を探し、1問ずつの領域を画像に切り出す（ページをまたぐ問題、見出しのルビにも対応）
- 正答PDFの表から各問の正答を読み取り、問題数と正答数が一致するか確認
- 選択肢の数（4択/5択）、B問題の形式（穴埋め1〜10 / 正誤1・2）を判定
- ジャンルを判定し、過去の回とほぼ同じ問題（類似問題）を検出

- 問題ごとに「文字で表示」用のデータを作り（`tools/textview.py`）、選択肢番号の欠けなどを検査して、通らない問題は原本の画像だけにする
- 解説を付ける（`tools/explain.py`：正答を入れた文・モールス符号の読みを自動で作り、`explanations/` の手書きの解説と法改正の注記を取り込む）

選択肢数を自動判定できなかった問題は「要確認」と表示されるので、画像を見て `tools/build_data.py` の `CHOICE_OVERRIDES` に書き足してください。ジャンルの手動修正は `tools/genres.py` の `OVERRIDES` に書きます。文字表示を原本と並べて確認するには、HTTPサーバーを起動して `tools/qa.html`（`?ids=HZ711-A03,HY705-B04` のように問題IDで絞り込み可）を開きます。

### 解説を書き足す

`explanations/<試験コード>.md`（例: `explanations/HZ711.md`）に、問題番号の見出しの下に解説を書きます。空行で段落を分け、`**強調**` が使えます。別の問題と同じ解説にするときは見出しに `= 問題ID` を付けます。

```markdown
## A-1
正しいのは2（第2条第4号）。…

## B-3 = HY808-B02
```

書いたら、画像を作り直さずに解説だけを入れ直せます。

```sh
python3 tools/build_data.py --explain-only
```

法改正の注記は `explanations/outdated.md` に `## 問題ID | 改正法令 | major または minor` の見出しで書きます。新しい回を追加したときや法令が改正されたときは、`python3 tools/lawcheck.py` で引用条文の改正を洗い出せます（結果は `lawcheck.txt`。答えに影響するかは人が判断して `outdated.md` に書く）。

## 開発

```
index.html, css/, js/        アプリ本体（ビルド不要の素のJavaScript）
  js/engine.js               採点・復習スケジュール・出題選択（DOMに依存しない）
  js/store.js                学習記録の保存
  js/views/                  各画面
sw.js, manifest.webmanifest  オフライン対応（PWA）
data/questions.json          問題データ（1問1行。文字表示用のブロックも含む）
data/img/<試験コード>/        1問ずつの問題画像（A01.png）と文字表示用の図・式の画像（A01_t1.png, A01_m1.png）
source-pdf/                  日本無線協会が公表した問題・正答PDF（変換元）
explanations/                手書きの解説（<試験コード>.md）と法改正の注記（outdated.md）
tools/build_data.py          PDF → 問題データ変換スクリプト
tools/textview.py            問題文を「文字で表示」用に組み直す処理
tools/explain.py             解説の自動生成と取り込み
tools/lawcheck.py            法規の引用条文の改正を調べる（e-Gov 法令API）
tools/genres.py              ジャンルの定義と自動分類
tools/qa.html                文字表示と原本の比較ページ（開発用）
tests/                       単体テスト
```

```sh
node --test tests/engine.test.mjs
```

## 出典と利用条件

問題・正答の著作権は公益財団法人日本無線協会に帰属します。同協会のウェブサイトには「英語の科目の試験問題を除き、国家試験の受験など試験制度の意義に反しない場合に限り、公表されている過去の試験問題を無償で問題集等に使用することができます。この場合、当協会に許諾を求める必要もありません。」と記載されており、本アプリはこの条件のもとで公表された問題を収録しています（1アマに英語の科目はありません）。
