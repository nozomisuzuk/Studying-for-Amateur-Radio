## A-1
平行平板コンデンサの静電容量は C = εS/d で、比誘電率に比例し電極間距離に反比例する。50 × 4 × 2 = **400〔pF〕**。

## A-2
ビオ・サバールの法則：ΔH = IΔl sin θ/(4πr²)。θ = 60° で sin 60° = √3/2 なので、ΔH = **√3 IΔl/(8πr²)**。

## A-3
立方体の対角の頂点間（各辺 R）。対称性から a から出る3本、b に入る3本の抵抗には電流 I/3、その間の6本には I/6 が流れる。

Vab = R × I/3 + R × I/6 + R × I/3 = 5RI/6 なので、合成抵抗は **5R/6**。

## A-4
A＝**0**、B＝**XL/R**、C＝**(1/R)√(L/C)**。共振時は C と L の電圧が大きさ等しく逆位相で打ち消し合い Vab = 0。電流は I = V/R なので VL = I XL = (XL/R)V。尖鋭度 Q = ω0L/R = (1/R)√(L/C)。

## A-5
ブリッジの平衡条件（向かい合う辺のインピーダンスの積が等しい）：(R1 + 1/(jωC))(R4 + jωL) = R2R3。

虚部が 0 になる条件 ωLR1 − R4/(ωC) = 0 より ω² = R4/(LCR1)、f = **(1/2π)√(R4/(LCR1))**。

## A-8
ドレイン側は電流源 gmVgs に rd と RL が並列。rd∥RL = 15 × 5/(15 + 5) = 3.75〔kΩ〕、電圧増幅度 = 8×10⁻³ × 3.75×10³ = **30**。

## A-10
上の AND は A・B、下の AND は Ā・B̄、OR でまとめて X = AB + ĀB̄（一致回路、排他的論理和の否定）。A と B が等しいとき 1 なので、真理値表は 1, 0, 0, 1（**1**）。

## A-11
2波3次の相互変調積は 2f1 − f2 又は 2f2 − f1。2 × 438.52 − 439.36 = **437.68〔MHz〕**（もう一方の 2 × 439.36 − 438.52 = 440.20〔MHz〕は選択肢にない）。

## A-12
誤りは5。SSB は、DSB に比べて**選択性フェージングの影響が小さい**。DSB では搬送波と側波帯が別々にフェージングを受けてひずみが大きくなるが、SSB は搬送波を送らず受信側で局部発振器から作るので、その影響を受けにくい。

4：100〔%〕変調の DSB は搬送波 Pc、側波帯が各 Pc/4 で合計 1.5Pc。片側の側波帯 Pc/4 は全体の 1/6 で正しい。

## A-14

## A-17
コンデンサ入力の全波整流で無負荷のとき、コンデンサは入力の最大値 Vm = 200√2 ≒ 283〔V〕まで充電される。ブリッジ形では、逆方向にかかるダイオードには入力の最大値がかかるので、逆電圧の最大値は **283〔V〕**。

## A-19
放射電力 Pr = I² × Rr = 3² × 36 = **324〔W〕**。放射効率 η = 36/50 = **72〔%〕**。

## A-21
A＝**1/2**、B＝**π**、C＝**4**。半波長のうかい線路で点 b の位相は a より π 遅れ、a と b の電圧が逆相になって平衡になる。平衡側の電圧は不平衡側の2倍、電流は 1/2 になるので、インピーダンスは **4倍**。

## A-24
27〔dB〕= 30 − 3〔dB〕で 1,000/2 = 500 倍。送信機の出力は 10〔mW〕× 500 = **5〔W〕**。

## A-25
