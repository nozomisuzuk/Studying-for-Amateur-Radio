## A-2
電荷保存で解く。S1を閉じたとき C1 の電荷 Q = C1 × 12 = 3〔μF〕× 12〔V〕= 36〔μC〕。S1を開きS2を閉じると、この電荷が C1 と C2 に分かれて両端の電圧が等しくなるので、Q = (C1 + C2) × 4。

36 = (3 + C2) × 4 より **C2 = 6〔μF〕**。

## A-3

## A-4
Cv と C は並列なので合成容量 C0 = Cv + C。共振条件 f = 1 / (2π√(L C0)) より、

C0 = 1 / ((2πf)² L) = 1 / ((2π × 7.05×10⁶)² × 2×10⁻⁶) ≒ 255〔pF〕、Cv = 255 − 125 ≒ **130〔pF〕**。

直列共振回路の Q = ωL / R = 2π × 7.05×10⁶ × 2×10⁻⁶ / 4 ≒ **22**。

## A-6
RL直列回路に直流電圧を加えたときの電流は i = (V/R)(1 − e^(−(R/L)t))。時定数 τ = **L/R**〔s〕のとき、i は定常値 V/R の 1 − e⁻¹ ≒ **63.2〔%〕**。電流は 0 から増加して V/R に近づくので変化は**図2**。

## A-8
32〔dB〕= 20 log₁₀ G より G = 10^(32/20)。32 = 20 + 12 で、20〔dB〕= 10倍、12〔dB〕= 6 + 6〔dB〕≒ 2 × 2 = 4倍なので G ≒ 40倍。

反転増幅回路の電圧利得の大きさは R2 / R1 なので、R2 / R1 = 40 となる組合せは **R1 = 1〔kΩ〕、R2 = 40〔kΩ〕**。

## A-12
無変調の搬送波の振幅 Ec = 80〔V〕。AM波の実効値は E = (Ec / √2)√(1 + m²/2)。

60 = (80/√2)√(1 + m²/2) より 1 + m²/2 = 2 × 60² / 80² = 1.125、m² = 0.25、**m = 0.5（50〔%〕）**。

## A-15

1 はスケルチ回路、2 はディエンファシス回路、3 はノイズブランカの説明。

## A-16

セル電圧は約3.6〜3.7〔V〕程度と高く（1）、エネルギー密度も高い（3）。過充電・過放電に弱いので保護回路を備える（2・4）。

## A-17
コンデンサ入力形平滑回路の無負荷出力電圧は、変成器2次側電圧の最大値に等しい。2次側の実効値を V2 とすると √2 V2 = 50√2 より V2 = 50〔V〕。

巻数比 2:1 なので 1次側の実効値 Vi = 2 × 50 = **100〔V〕**。

## A-19
1/4波長整合回路（Q変成器）では、入力側から見たインピーダンス Zin と負荷 Ra の間に Z0² = Zin × Ra の関係がある。送受信機側の 75〔Ω〕ケーブルと整合するには Zin = 75〔Ω〕なので、

Ra = Z0² / Zin = 50² / 75 ≒ **33〔Ω〕**。

## A-21
放射電力 Pr = I² × Rr = 1.5² × 36 = **81〔W〕**。放射効率 η = Rr / R = 36 / 41 ≒ 0.878、約 **88〔%〕**（入力抵抗 41〔Ω〕のうち 5〔Ω〕は損失抵抗）。

## A-25
直流電圧計の内部抵抗を r とする。最大目盛 5〔V〕の電圧計に 200〔kΩ〕を直列に入れると測定範囲が 25〔V〕（5倍）になるので、(r + 200) / r = 5 より r = 50〔kΩ〕。

400〔kΩ〕を直列に入れると倍率は (50 + 400) / 50 = 9 倍で、最大電圧は 5 × 9 = **45〔V〕**。

## B-1
ア：○ FSK は周波数偏移変調。

イ：× GMSK は、ベースバンド信号に**ガウスフィルタ（低域フィルタ）**をかけてから MSK 変調する方式。HPF ではない。

ウ：× PSK は搬送波の**位相**だけを変化させる（振幅は一定）。

エ：× QAM は搬送波の**振幅と位相**を変化させる（直交する2つの搬送波をそれぞれ振幅変調して合成）。

オ：○ OFDM は高速データを多数の低速データ列に分け、直交する多数のサブキャリアで並列伝送する。

## B-5
SG（標準信号発生器）：基本構成は発振器、**変調器**、出力計及び減衰器で、**出力端子以外**からの信号の漏れを防ぐよう厳重に遮へいされていること（ア・イ）。発振周波数・出力が正確で安定し、可変**できる**こと（ウ）。**出力インピーダンス**が既知で一定であること（エ）。スプリアスレベルが**低い**など低雑音であること（オ）。
